## 📱 텔레그램 실전 명령어

* `/start`: 봇 상태와 최근 발행된 글 목록 확인
* `/write 최신 AI 트렌드 요약`: 지정한 주제로 AI가 3개 섹션 개요를 실시간 기획
* `/write https://example.com/article 이 기사 요약해서 글 작성`: 외부 URL을 자동 크롤링하여 블로그 글로 재가공

기획안을 확인하고 **`[✅ 즉시 발행 및 배포]`** 버튼을 누르면, 라즈베리파이의 배포 엔진이 Git 커밋을 생성하고 GitHub Actions를 통해 약 1분 만에 전 세계로 라이브 배포됩니다!
